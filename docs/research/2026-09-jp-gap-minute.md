# 分足で gap 戦略の入口・出口・フィルタを検証する（2026-09-05）

`jp_gap_fade`（ロング）と `jp_gap_up_short`（ショート）を、取り込んだばかりの分足
（`equities_bars_minute`、2024-09〜2026-09）で検証した。「寄付で建てて引けで手仕舞う」の
日足の近似を分足の約定値に置き換え、**いつ入るか・いつ出るか・寄り後の形や需給で選べるか**を問うた。
設定は `config/daytrade_margin` の本番相当（現金 200 万・ロング 300 万 N3 + ショート 200 万 N3・
滑り 5 bp・12 月休み・前夜の米国ゲート・張り付き係数 1.0）。期間は引けが 15:30 になった
**2024-11-05〜2026-09-04 の 448 営業日**（それ以前の 2 か月は引けが 15:00 で出口の比較にならない）。
探索は使い捨てのスクリプトで行った（パネルは `backtest.LoadPanel` そのもの、約定は `FillModel` の
差し替えで、骨組みは `daytrade backtest` と同じ）。**採用した部分は `daytrade` に入れてある**——
表の主要な数字はコマンドで再現できる（末尾「実装」）。

## 結論（先に）

1. **利益は「特別気配で寄付が遅れる銘柄」に集中している。** 建てた銘柄のうち 09:00 に寄らないものが
   ロング 72%・ショート 94%。09:00 に寄った銘柄だけで回すと 2 年で **−13 万円**（ロング +4 万・ショート −17 万）、
   遅れた銘柄だけなら **+529 万**（基準 +492 万より良い）。この構造は、実運用の 9:01 の判断が
   「まだ寄っていない銘柄の気配」を見られるかどうかに**戦略の成否そのもの**が懸かっていることを意味する（後述）。
2. **出口は引け（クロージング・オークション）が最悪。** 15:20〜15:24 の成行のほうが両脚とも良く
   （合算 +470 万 → +525 万、Sharpe 2.87 → 3.20、MaxDD −88 万 → −73 万）。ギャップダウン銘柄の引け値は
   15:24 の値より平均 −5 bp、ギャップアップ銘柄は +4 bp（3 年とも同じ向き）。**今の cron（15:20）は正しく、
   バックテストのほうが保守的**。分足の `FillModel` を入れれば検証と実運用が揃う。
3. **入口は 1 分ごとに減る。** ロングは寄付 → 09:01 で −12%、09:05 で −35%、09:10 で −65%、09:30 でゼロ。
   ショートは 09:01 までほぼ同じ（寄付自体が遅いため）、09:10 で −32%。今の 9:01 は「寄付」と「遅れて寄る銘柄は
   板寄せで約定」の組み合わせでほぼ最善だが、**09:00 に既に寄っている銘柄は 9:01 に買うと平均 +27 bp 高く買う**
   （ショートは −146 bp 安く売る）。この銘柄群は利益が無いので、**9:01 に「もう寄っている銘柄」を候補から外す**のが
   実装可能な改善（合算 +492 万 → +529 万）。
4. **場中の損切り・利確・トレーリングは全滅**（10 年の日足での結論と同じ）。ロングの損切り 2% で −38%、5% で −12%、
   トレーリング 2% は損益ゼロ。利益は「寄付の過剰反応が戻る」ことから出ており、逆行に耐えて持つことが条件。
5. **ロングの利益は前場で出尽くす。** 上位 3 銘柄の平均は 09:30 に +33 bp で、その後 15:20 まで横ばい（+27 bp）。
   ロングだけ 10:30 に手仕舞うと利益 −19%（2 年）で **MaxDD が半分**（−62 万 → −30 万）、Sharpe 2.25 → 2.35。
   ショートは 11:00 までに 85%、15:00 までじわじわ伸びるので引けまで持つ。
6. **需給データ**: 信用倍率（週次 `margin-interest`、買残 ÷ 売残）が高い銘柄はロングで弱い。2 年では
   ≥ 10 倍を外すとロング +32%・Sharpe 1.98 → 2.96・MaxDD −65 万 → −33 万だが、**10 年の日足では +4% で 2021・2022 年は悪化**。
   採用は保留（2024 年以降に偏った効き）。空売り残高報告・寄り付きの出来高比・寄り後 1〜5 分の反発/続落は
   安定した層別にならなかった。

## 分足の性質（使う前に確かめたこと）

- 09:00 の足の `O` は日足の始値と**全銘柄で一致**、最終足の `C` は日足の終値と一致（2026-09-04・2024-10-01 で確認）
- 引けは 2024-11-05 から 15:30。15:25〜15:29 の足は無く、15:30 の足がクロージング・オークション
- 昼は 11:30 の足まで、12:30 から再開
- 約定の無い分は行が無い。**特別気配で寄付が遅れる銘柄は最初の足が 09:0x**（この「遅れ」が本研究の主役）
- 「T に成行を出した」は **T 以降の最初の足の `O`**、「T の値洗い」は **T 以前の最後の足の `C`** で近似した。
  板が無いので、成行の建値は約定値と同じ（スプレッドの半分ぶんは見ていない。後述）

## 発見 1: 利益は「寄付が遅れる銘柄」に集中している

建てた銘柄（基準: 寄付で建て 15:20 で手仕舞い）の最初の約定時刻:

| 脚 | 年 | 件数 | 09:00 に寄らない | 09:05 まで寄らない | 09:10 まで寄らない | 損益: 遅れた | 損益: 遅れない |
|---|---|---|---|---|---|---|---|
| ロング | 2025 | 352 | 68% | 33% | 8% | +74 万 | +51 万 |
| ロング | 2026 | 276 | 90% | 55% | 12% | +114 万 | −6 万 |
| ショート | 2025 | 184 | 89% | 85% | 20% | +68 万 | +5 万 |
| ショート | 2026 | 187 | 99% | 97% | 37% | +231 万 | −19 万 |

ポートフォリオで分けると（9:01 成行・15:20 成行）:

| 母集団 | 合算 | Sharpe | MaxDD | ロング | ショート |
|---|---|---|---|---|---|
| 基準（全部） | 492 万 | 3.02 | −76 万 | 218 万 / 651 件 | 274 万 / 380 件 |
| **09:00 に寄った銘柄を外す** | **529 万** | 3.03 | −79 万 | 226 万 / 540 件 | 304 万 / 360 件 |
| 遅れた銘柄を外す（09:00 に寄った銘柄だけ） | −13 万 | −0.16 | −113 万 | +4 万 / 671 件 | −17 万 / 30 件 |

読み取り:

- 大きなギャップは特別気配を経て寄る。その板寄せの価格が「過剰反応」で、そこから戻るのが利益。
  09:00 にすんなり寄る程度のギャップ（ロングの中央値 −2.1%、遅れる群は −3〜−13%）には戻りが無い
- 09:00 に寄った銘柄を 9:01 に成行で買うと、最初の 1 分の反発ぶん **+27 bp**（ロング上位 3、p90 +48 bp）高く買う。
  ショートは **−146 bp** 安く売る（09:00 に寄ったギャップアップ銘柄は最初の 1 分で崩れる）。遅れる銘柄は
  9:01 の成行が板寄せに参加するので建値 = 寄付で、この滑りが無い
- 「09:00 に寄ったか」は **9:01 の時点で分かる**（始値 `pDOP` が入っているか）。除外は実装できる

### 実運用への含意（最重要）

`open` は「寄付後は始値 `pDOP`、寄り前は現在値 `pDPP`」でギャップを出す（`wbcore.broker.tachibana_price`）。
9:01 の時点で利益源の銘柄は**まだ寄っていない**ので、`pDPP` が何を返すかで戦略の成否が決まる:

- `pDPP` が**前日終値のまま**なら、ギャップ 0 → ロングの `max_gap = 0` にもショートの `min_gap = 0.05` にも掛からず、
  **利益源の 7〜9 割の銘柄が候補から消える**。残るのは 09:00 に寄った銘柄 = 利益ゼロの群
- `pDPP` が**特別気配の気配値**なら、そのギャップで順位を付けて成行を出せば板寄せで寄付で約定する（本研究の「基準」に相当）

これは `docs/OPENING_DATA.md`「実機で確かめること」の 3（寄り前に気配が返るか）そのもので、
**発注経路を開ける前に立花の実機で確かめる**必要がある。気配値が `pDPP` に入らないなら、板の列
（特別気配の値段）を `MarketPriceColumns` に足して、`selection` がそれをギャップに使う改修が要る。
気配値そのものは J-Quants に無いので、この経路の検証は板の記録（`daytrade snap`）が溜まってから。

15:20 の成行売りは最良買気配で約定するので、ここで見た「引けより +4〜5 bp」は**スプレッドの半分**と同じ桁

スプレッドは無い**ので、この差は板の記録（15:19 の `snap`）で実測してから確定させる。少なくとも
「15:20 が引けより悪い」ことは無い。

## 提案（優先順）

1. **実機で `pDPP` の寄り前の値を確かめる**（発注経路を開ける前に必須）。特別気配の気配値が入らないなら、
   気配の列を足して `selection` がそれでギャップを出すようにする。これ無しでは利益源の 7〜9 割が候補に載らない
2. **9:01 の順位付けで「既に寄っている銘柄（`pDOP > 0`）」を外す**。利益が無い群を外し、1 分の反発ぶんの
   滑り（ロング +27 bp・ショート −146 bp）を避ける。合算 +492 → +529 万（2 年）。`selection.Rank` に条件を 1 つ足すだけ
3. **バックテストの `FillModel` を分足にする**（`docs/DAYTRADE.md` の予定どおり）。建値 = 9:01 以降の最初の約定、
   手仕舞い = 15:20 以降の最初の約定。分足が無い期間（2024-09 以前）は日足のまま。検証が実運用に揃い、
   引けの逆風（−5 bp）を織り込んだ数字になる
4. **ロングの出口を 10:30〜11:25 に前倒しする案**を候補に置く。利益 −6〜−10% で MaxDD 半分。2 年の結果なので、
   分足が溜まるまで（もう 1 年）は既定を変えず、`evaluate` に「前場引けの値」を足して毎日測る
5. **信用倍率 ≥ 10 の除外**は候補として記録のみ。10 年で +4%・2021〜22 年は悪化
6. 損切り・トレーリング・寄り後の形での選別・空売り残高・出来高比は**入れない**

## 実装（2026-09-05 追記）

上の提案 2〜5 を `daytrade` に入れた。1（実機で `pDPP` を確かめる）は立花の資格情報が要るので未了で、
これが済むまで `skip_opened` は既定 false のまま。

| 提案 | 入れたもの |
|---|---|
| 3. 分足の `FillModel` | `backtest.MinuteBars` と `daytrade backtest --fill-entry / --fill-exit`。分足の無い日は日足の寄付・引けに落ちる（10 年の検証は止まらない）。端点は `universe.EPMinute` |
| 2. 既に寄っている銘柄を外す | `signal.skip_opened`（**既定 false**）。実運用は `quotes.DropOpened` が気配そのものを落とす（両脚に効く）、検証は `backtest.Options.Opened` が分足の最初の約定で判定する。設定に関わらず `history/quotes.opened` に毎日記録 |
| 4. 前場引けを測る | `history/evaluation` の `midday` / `midday_gross_bp` / `midday_net_bp`（`evaluate.MiddayFor`）。**出口は 15:20 のまま** |
| 5. 信用倍率 | `history/plan` と `state/daytrade/plan-*.parquet` の `margin_ratio`（`universe.loadMarginRatio`）。**母集団の条件には入れない** |

実装した `daytrade backtest` で本研究の表を再現できる（2024-11-05〜2026-09-04、`config/daytrade_margin`）:

```bash
daytrade backtest --config-dir config/daytrade_margin --since 2024-11-05 --fill-entry 09:01 --fill-exit 15:20
#   合算 492 万 / Sharpe 3.02 / MaxDD −76 万（ロング 218 万・ショート 274 万）
# signal.skip_opened = true にすると
#   合算 529 万 / Sharpe 3.03 / MaxDD −79 万（ロング 226 万・ショート 304 万）
```

`--fill-exit` を外せば引け（日足の終値）に戻るので、発見 2 の「引けの板寄せは逆風」も
コマンド 2 本で確かめられる。

## 割り引くべき点

- 期間は 448 営業日（2024-11〜2026-09）で、2025〜2026 は両脚とも良い年。10 年の日足では検証できない項目
  （入口・出口の時刻、寄付の遅れ）は 2 年の結果でしかない
- 板が無いので、成行の建値・手仕舞い値は約定値と同じとした。スプレッドの半分（呼値 1 円 = 3〜6 bp）は
  15:20 の出口にも 9:01 の入口にも乗る。引けの板寄せにはこれが無いので、発見 2 の差は板で測り直す
- 「寄付で建てる」は板寄せに成行を入れられた場合の値。特別気配で遅れる銘柄は 9:01 の成行で間に合うが、
  09:00 に寄る銘柄の寄付は実運用では取れない（8:59 の気配で寄成を出さない限り）
- 分足は東証の現物のみ。ショートの張り付き（`carry_penalty`）は日足の判定のまま
