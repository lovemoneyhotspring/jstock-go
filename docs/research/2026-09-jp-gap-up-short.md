# 日本株デイトレのショート戦略 — 銘柄選定・データ・戦略の検討（2026-09-02）

`2026-08-jp-daytrade-selection.md`「信用売り（2026-09-01 追記）」の続き。既存のショート脚
`jp_gap_fade_margin` は「プライム × ギャップ +3% × ロングが弱い日だけ」のシーソー型で、ロングの補完が目的だった。
ここでは**ショート単体で成り立つ戦略**を、J-Quants Standard のアーカイブ（2017-01〜2026-08）で探した。
立花証券 e支店（信用手数料 0 円・貸借銘柄の新規売り・日計り）、現金 200 万円、1 注文 67 万円・N=3、
往復コスト 5.3 bp（貸株料 1 日分 + 滑り 5 bp）、100 株単位、50 単元（5,000 株）上限。スクリプトは使い捨て（scratchpad）。

## 結論（先に）

1. **効くのは「決算なし × 大きなギャップアップ（寄付 ≥ 前日終値 +5%）を寄付で売り、大引で買い戻す」**。
   ギャップが大きいほど効く（5〜7%: +29 bp、7〜10%: +79、10〜15%: +112、15% 以上: +304 bp/取引）。
   単純な検証では 10 年で 1,083 万円・Sharpe 2.31・IS 2.93 / OOS 1.61・MaxDD −64 万・負け年 1（2023）。
2. **ただし「引けがストップ高で返済買いが約定しない」持ち越しが 5.4%（185 件）あり、翌朝までにさらに平均 −425 bp**。
   これを全額織り込むと 611 万・Sharpe 1.09・OOS 0.32・MaxDD −162 万まで落ちる。**場中の損切りは逆効果**（往復ビンタ）。
   張り付きにくい母集団（プライム）に絞るのが現実解: ペナルティ全額で 458 万 / Sharpe 1.22 / DD −88 万 / **負け年 0**、
   半分なら 570 万 / 1.64 / −60 万。
3. 信用残・空売り・規制のデータは**ショートの銘柄選定には使えない**。「日々公表・規制銘柄のギャップアップを売る」は
   走査では +31〜51 bp/取引と最も強く見えたが、その効きは**売り禁（日証金 申込停止 = 新規売りできない）銘柄**が作っていた。
   建てられる規制銘柄だけにすると ≈ 0。
4. **決算翌日のギャップアップは絶対に売らない**（−24〜−30 bp/取引、勝率 44%）。決算翌日のギャップダウン順張りは弱い（+8〜+13 bp）。

## 発見 1: 規制銘柄の効きは「売り禁」が作っていた

`margin-alert` の `PubReason` を分けると（銘柄日）: 日証金 貸株注意喚起 72,734・**申込停止（売り禁）46,257**・日々公表 13,066・東証 増担保 3,361。

| 規制の理由 × ギャップ ≥ +2%、N3 | 10 年合計 | Sharpe | 負け年 |
|---|---|---|---|
| 日々公表 | −5 万 | −0.04 | 5 |
| 日証金 注意喚起 | 187 万 | 0.47 | 5 |
| 東証 増担保 | −87 万 | −2.12 | 7 |
| 規制あり（売り禁除く） | 152 万 | 0.35 | 3 |
| **売り禁（建てられない）** | **1,065 万** | **2.03** | **0** |

売り禁は「借りられないから売れない」銘柄で、売れないからこそ上がり、翌日に落ちる。取れないプレミアム。
`2026-08-jp-alt-data-scan.md` の「日々公表の対象は −435 bp/60 日」も同じ理由で割り引く必要がある。

## 発見 3: 最大のリスクは「ストップ高張り付き → 返済買いが約定しない」

引けがストップ高（`C ≥ prev_close + 値幅`）の取引が **5.4%（185 / 3,402 件）**。その取引の平均損益 −4.6 万に加え、
翌朝の寄付までに **さらに −425 bp**（翌寄りが下がる確率 31%）。買い気配で張り付いた板では成行の返済買いは約定しないので、
この持ち越しは避けられない（15:20 の成行でも同じ）。張り付き率は growth 5.3% / standard 5.8% / **prime 2.1%**、
過熱銘柄 8.3% / それ以外 2.1%、ギャップ 15% 以上 17.7%。年別では 2017 と 2024〜2026 に多い。

**持ち越しペナルティ込み**（張り付き → 翌寄りで返済、全額 / 半分）:

| 母集団（ギャップ ≥ 5%・N3） | 全額 | 半分 | 無し |
|---|---|---|---|
| 全区分 | 611 万 / 1.09 / −162 万 / 負け 2 | 847 / 1.67 / −89 / 1 | 1,083 / 2.31 / −64 / 1 |
| **プライム** | **458 / 1.22 / −88 / 0** | **570 / 1.64 / −60 / 0** | 681 / 2.06 / −50 / 0 |
| プライム × 時価総額 上位 2/3 | 314 / 1.37 / −53 / 2 | 358 / 1.66 / −47 / 2 | 402 / 1.95 / −40 / 1 |
| 全区分 × 過熱でない × 小型でない | 304 / 1.42 / −71 / 3 | 336 / 1.64 / −63 / 1 | 368 / 1.84 / −56 / 1 |

**効かなかった対策**:
- ストップ高までの余地 ≥ 5% / 8% で除外 → 悪化（429 / 0.80、349 / 0.70）。余地の小さい取引が利益源でもある
- 余地に応じて建玉を縮める（ストップ高まで行っても損失 ≤ 5 万） → 378 / 0.98。ペナルティは建玉に比例するので縮小では消えない
- **場中の損切り（寄付 +X%、日足 H で近似、滑り 30 bp）** → 全滅。+4% で 32% が損切りに当たり 270 万 / 0.67、+8% で 243 / 0.61、
  +10% で 436 / 1.17。日中の最大逆行は中央値 +2.3%・90% 点 +8.0% で、**この戦略の利益は逆行に耐えて引けまで持つことから出ている**
- ボラの小さい順・N5・15 bp + 滑り 50 bp も改善しない

残る対策は「張り付きにくい母集団（プライム）に絞る」と「実際の約定率を運用で測る」。J-Quants の日足では
「引けがストップ高」と「張り付き（買い残あり）」を区別できないので、ペナルティの実態は全額と 0 の間にある。

既存脚との関係: 既存の `jp_gap_fade_margin` のショート（プライム × ≥ 3% × 弱い日）と日次相関 0.53（母集団が重なる）、
ロング脚 `jp_gap_fade` とは −0.07。ペナルティ無しでは「ロング + 本戦略（常時）」が 2,202 万 / Sharpe 2.67 / MaxDD −71 万
（現行「ロング + 既存脚（弱い日）」1,363 / 1.95 / −100）だが、ペナルティ込みの合成は `daytrade backtest` に組み込んでから見る。
**既存のショート脚を本戦略で置き換える**のが素直（閾値 3% → 5%、シーソー → 常時、売り禁だけ除外）。

## 割り引くべき点

- 日足だけの検証。寄付は「9:00 の始値で約定」の仮定で、特別気配で寄りが遅れる銘柄は実際にはもっと悪い値になる
- 張り付きの持ち越しペナルティは上限（全額）と下限（0）の間。運用の最初の数か月は N=1〜2 で約定率を測る
- 空売り価格規制（前日終値比 −10% でトリガー）は 50 単元以下なら適用外。上限 5,000 株の理由でもある
- 2018・2020 の急落局面が利益の一部を作る（上位 10 日 16%）。2023 型の上げ相場は負け年
- 検証は 2017-01〜2026-08 の同じ 10 年で IS/OOS を切っただけ。閾値（5%）と N（3）以外は既存ロングの値をそのまま使った

## 実装（2026-09-02 追記）

上の「実装に要るもの」1〜4 を `daytrade` に入れた（5・6 は運用で）。

- `daytrade.universe.jsf_stop_expr` / `short_eligible_expr`: `margin-alert` の `PubReason.RestrictedByJSF` を売り禁フラグにし、
  ショート専用の母集団（`[margin]` の `segments` / `min_turnover` / `exclude_cap_terciles` / `exclude_earnings_*` /
  `exclude_margin_alert` / `exclude_jsf_stop`）を `candidates`（plan の `short_eligible` 列）と `load_panel` で同じ式にした
- `[margin]` の既定を `segments = ["prime"]`・`min_gap = 0.05`・`multiplier_normal = multiplier_long_weak = 1.0`（常時）に。
  `open` は `plan.short_eligible` から `rank_short` し、気配はロングとショートの和集合で取る
- `daytrade.backtest._apply_carry`: 引けがストップ高の売建を翌営業日の寄付で返済したことにする（`margin.carry_penalty`、既定 1.0）。
  `backtest` は張り付きの件数と損益を出す

`config/daytrade_margin` の本番相当（現金 200 万・ロング 300 万 N3 + ショート 200 万 N3・滑り 5 bp・12 月休み・前夜の米国ゲート）で
2017-01〜2026-08: 合算 1,923 万 / Sharpe 2.35 / MaxDD −82 万、ロング 1,212 万 / 2.21 / −71 万、
**ショート 711 万 / 1.12 / −102 万（張り付き 57 / 1,530 件 = 3.7%、該当の損益 −448 万）**。年別は全年黒字（ショート単体は 2019・2023 が負け）。
ショートは危険信号（12 月・前夜の米国）でロングと一緒に休む設計のままで、稼働は 852 日。上の研究（ゲート無し・等金額）の
プライム限定・全額計上 458 万 / 1.22 より利益が多いのは、2026 年のショート +215 万と、ボラ逆数配分・ゲート日の除外による。
