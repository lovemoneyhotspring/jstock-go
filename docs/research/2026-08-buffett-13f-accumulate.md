# バフェット銘柄（13F 追従）積立の検証（2026-08）

## 問い

「S&P500 の積立が最強」と言われる一方、バークシャーの長期成績はそれを上回る。
バフェットの銘柄選定を積立に持ち込めば、S&P500（VOO）の積立を超えられるか。

## 前提と実装

- **配分層を新設**（`wbjp.accumulate.basket`）。従来の積立は「1銘柄に積立型戦略1つ、倍率だけを決める」
  構造で銘柄間の配分を持たなかった。バスケットは `予算 × 配分比率 × 倍率` の配分比率を担う。
- **13F はSEC EDGAR から取得**（`wbjp.data.edgar_13f`、`wbjp accumulate sync-13f`）。
  XML 化された 2013-Q2 以降、53 四半期。CUSIP→ティッカーは `config/cusip.toml`。
- **ルックアヘッド回避**: 比率は四半期末ではなく **提出日の翌営業日** から反映（最大 45 日遅れ）。
- **足の無い銘柄**（買収・上場廃止: DirecTV、Precision Castparts、Activision 等）は除いて正規化。
  買収は通常プレミアム付きなので、成績は実際より **控えめ** に出る方向のバイアス。
- 投下: 毎月 10 万円を入金日（月初営業日）に全額。約定は翌営業日の寄付。
- 物差し: XIRR（年率内部収益率）と、時間加重の評価額指数の最大DD。同じ日に同じ額を VOO に
  投じた場合を基準として並べる。

## 結果（2013-08 〜 2026-08、毎月 10 万円、総投入 1,560 万円）

| 戦略 | 期末 | XIRR | 最大DD | VOO 基準 XIRR | VOO 基準DD |
|---|---:|---:|---:|---:|---:|
| BRK 上位15（比率追従） | 3,874万 | +13.1% | 39% | +15.1% | 34% |
| BRK 上位10 | 3,820万 | +12.9% | 39% | +15.1% | 34% |
| VOO70 + BRK30（コア・サテライト） | 4,304万 | +14.6% | 35% | +15.1% | 34% |
| BRK 上位15 + 下落配列3倍（投入 1,854万） | 4,634万 | +13.1% | 39% | +15.2% | 34% |
| BRK 上位15 + 割安傾斜 ×2 | 3,872万 | +13.1% | 39% | +15.1% | 34% |
| BRK 上位15 + 割安傾斜 ×5 | 3,866万 | +13.1% | 39% | +15.1% | 34% |

### 期間別（BRK 上位15 vs VOO）

| 開始 | BRK XIRR / DD | VOO XIRR / DD |
|---|---:|---:|
| 2013-08 | 13.1% / 39% | 15.1% / 34% |
| 2016-01 | 15.0% / 39% | 16.0% / 34% |
| 2019-01 | **18.5%** / 39% | 17.0% / 34% |
| 2022-01 | 18.7% / 24% | 19.6% / 25% |

## 読み

1. **13F 追従は全期間で VOO に負け、DD も深い**（−2pt、+5pt）。2014〜2018 の IBM・
   WFC・KHC の不振が効いている。2019 年以降だけ見ると勝っており（AAPL 集中の恩恵）、
   結果は期間依存が大きい。「バフェットの選定」の超過リターンは、少なくとも
   13F 公開後に真似できる部分には、この 13 年では残っていなかった。
2. **コア・サテライトはほぼ VOO と同じ**（−0.5pt）。サテライトが足を引いているだけで、
   分散効果で DD が下がるわけでもない（構成銘柄が指数と高相関）。
3. **下落配列の増額（bear_stack ×3）は XIRR を変えない**。個別株は 200 日線割れが指数より
   頻繁で、増額が「その後も下がり続ける銘柄」に入りやすい。指数積立で効いた仕組みが
   個別株の籠ではそのまま効かない。
4. **割安傾斜（高値からの下落率で配分を寄せる）も効かない**。傾斜自体は動いている
   （2020-04 に AAPL 33%→28%、BAC/WFC へ寄る）が、寄った先が金融株で、その後の
   回復が指数に劣った。価格だけの「安さ」はバリュートラップを拾う。財務指標で
   質を担保しない限り、傾斜は改善にならない。

## 結論

- **積立の主軸は VOO のまま**。バフェット籠を混ぜる根拠は、この検証からは出ない。
- 混ぜるならコア・サテライト（VOO 70%）まで。成績は VOO と同等で、DD は僅かに悪化。
- 「バフェットに勝つ」なら次に試すべきは選定ロジックそのもの（ROE・FCF 利回りの
  定量スクリーン）だが、過去時点の財務データを yfinance からルックアヘッド無しに
  取るのが難しく、未着手。

## 再現

```
wbjp accumulate sync-13f          # EDGAR から 13F（data/13f/<cik>/holdings.parquet）
wbjp accumulate sync --force      # 構成銘柄（過去に登場した全銘柄）と基準の足
wbjp accumulate basket [--from 2019-01-01] [--weights]
```

設定は `config/strategies.toml` の `[[baskets]]`（統合前は `config/accumulate.toml`）。CUSIP の対応は `config/cusip.toml`
（未対応の CUSIP はログに `cusip_unmapped` で出る）。

## 落とし穴

- 一部銘柄の足が 2014-08 からしか無かった（以前の同期の範囲）。`sync --force` で埋め直す。
- BNY Mellon はティッカーが `BK` → `BNY` に変わっており yfinance で取れなかった。対応表で吸収。
- XIRR の二分法は、絶対誤差で打ち切ると長期系列で粗い解に止まる。金額に対する相対誤差にした。
- 入金日はバスケット共通の暦で決める。銘柄ごとに決めると途中上場の銘柄が上場初日に
  「その月の入金」を持ち、二重投入になる（テストで検出）。
