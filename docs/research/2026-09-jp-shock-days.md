# 経済イベント・為替・ショックと gap 戦略の損益（2026-09-05）

`config/daytrade_margin`（ロング `jp_gap_fade` + ショート `jp_gap_up_short`）の 10 年の日次損益
（2017-01〜2026-09、2,364 営業日、日足の寄付・引け）を、**前夜までに分かる出来事**で層別した。
問いは 2 つ: (1) 予定された経済イベント（FOMC・日銀・指標・選挙）や季節性・為替は銘柄選定に効くか、
(2) 予定できないショック（紛争・震災・原油の急変）が起きたときの損益はどうなるか。
併せて、ショート脚の損失の尻尾がどこから来ているかを取引単位で調べた。スクリプトは使い捨て。

## 結論（先に）

1. **予定された経済イベントは何も出ない。** FOMC・日銀・雇用統計・SQ・月初月末・曜日・月・選挙のどれも |t| < 1.2 で、
   IS と OOS で符号が割れる。28 個の検定で唯一 |t| > 2 だったのは水曜（−9,011 円/日）だが、仕組みが無く、28 個中
   1 個は偶然の期待値。季節性は 12 月（既に `skip_months`）だけ。
2. **為替は市場ギャップの代理変数。** 前夜のドル円の向きは無関係で、|Δ| ≥ 1% は +9,657 円/日（t = 1.75）に見えるが、
   市場ギャップを固定すると消える（ドル円 大 × 市場ギャップ 小 = 6,098 円 ≈ 基準 6,525 円）。原油も同じ。
3. **予期せぬショックは戦略の最良の日。** 前夜の VIX +5 pt 以上は +68,918 円/日（n = 36、t = 5.2、勝率 75%）、
   9:00 の市場ギャップ ≤ −2% は **+78,456 円/日（n = 37、t = 6.2、勝率 78%、IS 79k / OOS 77k）**。翌 5 日も基準の 2〜3 倍。
   効くのは**ロング脚だけ**で、ショートの勝率は 16〜26%。休むのは最悪（ショック日を全部休むと 1,649 → 1,239 万）。
4. **ショートの尻尾は「候補 1 銘柄の日」。** 最悪 20 日のうち 15 日はショート脚が主因で、13 日は市場が静かな日。
   最悪 20 取引のうち 13 件は金額 ≈ 200 万円（候補が 1 銘柄で総予算が全部乗った日）。N を増やす・等金額・極端な
   ギャップの除外は悪化し、**1 注文の上限 100 万円**だけが効く（Sharpe 0.87 → 1.03、MaxDD −117 → −75 万）。
5. 採用: `regime.shock_market_gap = shock_us_ret = −2%`、`config/daytrade_margin` で**ロング ×1.5・ショート ×0**、
   `margin.max_order = 100 万`、**`margin.spill_to_long`**（ショートの余りをロングに回す）。10 年で合算 1,649 → **2,110 万**、
   Sharpe 2.09 → **2.52**、MaxDD −88 → −82 万、保証金は現金の 82% のまま。
   **分足 2 年（9:01/15:20）では合算 492 → 442 万・Sharpe 3.02 → 2.90・MaxDD −76 → −71 万**——直近 2 年はショートが例外的に
   良く（2026 年 +205 万）、1 注文の上限がその大勝ちを削る。10 年の Sharpe と DD を取る選択で、利益は両期間とも減る。

## 2. 為替・原油

前夜のドル円（FRED `DEXJPUS`、NY の D−1）の 5 分位はすべて |t| < 0.6。|Δ| ≥ 1% は +9,657（t = 1.75）だが:

| | 市場ギャップ \|中央値\| ≥ 1% | 市場ギャップ 小 |
|---|---|---|
| ドル円 \|Δ\| ≥ 1% | +53,845（n = 40） | **+6,098**（n = 122） |
| ドル円 小 | +20,935（n = 261） | +6,525（n = 1,940） |

市場ギャップは 9:00 の気配から出して `regime.MarketGap` に既に入っている。原油（ブレント）も同じで、+5% 以上 +15,942
（t = 0.8）、−5% 以下 +25,315（t = 1.9）と向きに関係なく、|Δ| ≥ 8% で +33,789（t = 2.4）——市場ギャップ経由。

名前のあるイベント 22 件のうち当日がマイナスは 3 件だけ。震災 3 件（大阪北部 +196k、北海道胆振 +85k、能登 +166k）は
いずれもプラスだが市場ギャップはほぼゼロで、利益の大半はショート脚の 1 銘柄——「指数のショック」ではなく

COVID の FRB 緊急利下げ翌日（S&P +9.3%、翌 5 日 −175k）、ウクライナ侵攻（−49k）、ハマス攻撃（−60k）——
**安堵ラリーと、金融でない地政学ショックは翌週の信頼度が低い**。

ショートをショック日に建てないのは損益にほぼ影響せず（504 万 vs 509 万）、保証金の枠をロングに回すため。

「板が薄い朝に注文を 1.5 倍にしても同じ値で約定する」と仮定している。

## 4. ショートの尻尾

本番設定の最悪 20 日: 15 日がショート脚の損失が主因、13 日が前夜 |S&P| < 1% かつ市場ギャップ ±1% 内の静かな日。
ショート脚の最悪 20 日の合計 −357 万は 10 年利益 509 万の 70%（ロングは 24%）。取引単位では:

- 最悪 20 取引のうち **13 件が金額 ≈ 200 万円**——候補が 1 銘柄しか無く総予算が全部乗った日
- 張り付き（引けストップ高 → 翌寄り）は 57 件で −428 万。10〜15% のギャップ帯は 162 件で合計 −20 万（張り付き 22 件）と
  唯一の赤字帯だが、15% 以上は +129 万（+286 bp）で、上限で切ると悪化する（max_gap 0.15: 352 万）

| ショート脚の変種（10 年） | 損益 | Sharpe | MaxDD |
|---|---|---|---|
| 基準（N3・67 万・総予算を分け合う） | 509 万 | 0.87 | −117 万 |
| N4（50 万） / N5（40 万） / N6（33 万） | 413 / 343 / 347 万 | 0.71 / 0.59 / 0.59 | −126 / −137 / −145 万 |
| 等金額 | 457 万 | 0.75 | −106 万 |
| 資金 150 万（N3・50 万） | 340 万 | 0.78 | −87 万 |
| **1 注文の上限 100 万** | **428 万** | **1.03** | **−75 万** |
| 1 注文の上限 67 万 / 134 万 | 333 / 475 万 | 1.02 / 0.99 | −58 / −92 万 |

分散（N）は候補が足りないので次点の弱い銘柄を足すだけで悪化する。上限 100 万は分足 2 年（9:01/15:20）でも
Sharpe 2.10 → 2.17・MaxDD −46 → −43 万と同じ向き。

## 5. ショートの余りをロングに回す（`margin.spill_to_long`）

上限で切った資金と候補 0 の日の 200 万は遊んでいる。その日のロングに回し、ロングの銘柄数を総予算 ÷ 100 万
（`capital.max_positions` = 10 が上限）に増やす。長短の合計は 500 万のままなので保証金は変わらない。
ロングの 4〜10 位は 15:20 までの bp が上位 3 と同程度（+31 vs +27。研究ノート 2026-09-jp-gap-minute）なので、
枚数を増やしても質は落ちない。検証は日ごとに「ショートの使用額 → ロングの総予算 → ロングの選定」の順で決める
（`backtest.simulateMarginSpill`）。ショック日はショートの倍率が 0 で回す元が無く、ロング ×1.5 = 450 万にさらに
足すと枠を超えるので回さない。

| 10 年 | 合算 | Sharpe | MaxDD | ロング | ショート |
|---|---|---|---|---|---|
| 上限 100 万 + ショック ×1.5（前節） | 1,734 万 | 2.38 | −81 万 | 1,309 万 / 2.08 / −80 万 | 425 万 / 1.06 / −75 万 |
| **同 + 余りをロングへ** | **2,110 万** | **2.52** | −82 万 | 1,685 万 / 2.23 / −108 万 | 同 |
| 余りをロングへ、上限なし・ショック無し | 2,112 万 | 2.25 | −114 万 | 1,603 万 / 2.11 / **−142 万** | 509 万 / 0.87 / −117 万 |
| 余りをロングへ + 上限のみ | 2,154 万 | 2.49 | −94 万 | 1,725 万 / 2.22 / −128 万 | 428 万 / 1.03 / −75 万 |

分足 2 年（9:01/15:20）: 442 → **541 万**、Sharpe 2.90 → **3.18**、MaxDD −71 → −76 万。上限で削ったショートの利益
（10 年 −81 万、2 年 −95 万）をロングが取り返して余る。上限なしで回すとロングの DD が −142 万に膨らむ——
上限で「1 銘柄に 200 万」を止めた資金が、複数のロングに散って初めて効く。

## 実装

- `regime.shock_market_gap` / `shock_us_ret` / `shock_long_scale` / `shock_short_scale`（`regime.Evaluate` が `Verdict.Shock` と
  倍率を返す。`open` はロングの予算とショートの倍率に掛け、検証は `applyRegimeSeesaw` で同じ順序。`RequiredMargin` は
  ショック日の建玉も見る。`open_run.shock` に毎日記録）。土台 `config/daytrade` は倍率 1（現物は資金が無い）、
  `config/daytrade_margin` が 1.5 / 0 に上書き
- `margin.max_order`（`selection.PickOptions.MaxAmount`、検証は `legParams.maxAmount`）
- `margin.spill_to_long`（検証は `backtest.simulateMarginSpill`。`open` と `evaluate.ReconstructRanking` はショートを先に決め、
  余りでロングの N と 1 注文の予算を決め直す）

## 割り引くべき点

- ショック日の効きは 10 年で 124 日。2020 年 3 月と 2025 年 4 月が大きいが、除いても IS/OOS で一致する
- 倍率 ×1.5 は保証金から決めた値で、最適化していない。ショック日の最悪の 1 日は −27〜31 万で通常より重い
- 1 注文の上限は「候補 1 銘柄の日の大勝ち」も削る（利益 −16%）。Sharpe と DD を取る選択
- FOMC・日銀の日付は記憶ベース。効きが無いという結論は ±1 日の誤りで変わらないが、記録に載せるなら公式から取り直す
