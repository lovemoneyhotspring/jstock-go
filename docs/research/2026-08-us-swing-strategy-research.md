「勝率の高いスイングトレード」から出発し、SP500 に勝てるかを軸に
スクリーニング・出口・資金効率を順に検証した記録。次に戦略を検討する
ときは、**同じ実験を繰り返さないために**まずここを読む。

再現方法は末尾。データは yfinance 日足（`data/bars/`、gitignore）。
母集団は `config/us/universe.txt` の米大型株 91 銘柄（SPY 含む）。
初期資金 $30,000、手数料 0（Webull の米国株は 2026-07-27 から無料）。

## 0. 結論（先に読む）

| 問い | 答え |
|---|---|
| 個別株のスクリーニング＋順張りスイングで SP500 に絶対リターンで勝てたか | **勝てていない。** 唯一僅差で上回ったのは「RSI(3)<30 押し目買い ＋ 出口改善（L2）」で CAGR 18.6% vs SPY 17.4%（2019〜2026）。それも 25 通り超の探索の最良値 |
| 勝率の高いスクリーニングは機能したか | **入口は機能した。** 戦略の手仕舞いは勝率 90%。壊れていたのは出口 |
| 何が出口を壊していたか | 1.5×ATR の**場中**逆指値（全トレードの 36% で刺さり平均 −3%）、5 日の時間切れ（勝率 22%）、反転確認待ち |
| 出口を直すとどうなるか | 3 年で −6.5% → 7.6 年で CAGR 17%・DD 11.7%・勝率 82%（L2） |

| モメンタム／ETF ローテーションは | リスク調整後は SPY より良い（DD 1/3）が絶対リターンで負ける。上げ相場では構造的に SPY に勝てない |
| 絶対リターンで SPY を超えたもの | ベータを増やしたものだけ（SPY>SMA200 なら SSO: CAGR 17.8%・DD 37%、QLD: 25.8%・44%） |

## 1. 前提の整理

### 1.1 なぜ米国株か（2026-08-26）

- Webull JP は米国株の売買手数料が 2026-07-27 から恒久無料（SEC/FINRA 手数料のみ）
- 米国株は API で逆指値（STOP_LOSS）を置ける。日本株は非対応でエンジン合成（翌寄付判定）
- 1 株単位・呼値 0.01 ドル固定・制限値幅なし・差金決済規制なし
- 為替リスクと時差は残る

### 1.2 実装した基盤

- `wbcore.domain.market_rules`: JP / US の取引ルールの抽象化
- `wbjp.risk.stops.sync_broker_stops`: ブローカー逆指値の冪等な置き直し
- `effective_quantity` は逆指値を数えない（数えると買い直す）
- `[stops]` 設定: trailing / breakeven_after_r / stale_exit_days / max_hold_days（＋別セッションが take_profit_r / trend_exit_sma を追加）
- `wbjp screen`: 順位表と落選理由
- 戦略: `trend_pullback`（元 RSI(3) 押し目 → 別セッションが出来高枯れ＋ブレイクアウト型に書き換え）、`momentum_rank`（6M-1M リスク調整モメンタム、月次、`core_symbol` 受け皿）
- 設定: `config/us/`（押し目）、`config/us-momentum/`、`config/us-etf-rotation/`

### 1.3 見つけた不具合・罠（再発防止）

| 罠 | 症状 | 対処 |
|---|---|---|
| `data sync` は過去を埋め戻さない | 先に同期した銘柄だけ履歴が短く、ウォームアップで評価不能 → バックテストが 5 トレードしか出ない | `--force --days N` で取り直す |
| `max_order_value` が絶対額 | 資産が増えて 1 銘柄分が上限を超えると**全部の買いが弾かれ現金のまま止まる**。12 年のテストで 2021 年以降が +0% になった | 等分戦略では十分大きく取る。事故防止は `max_position_weight` に任せる |
| サイザーが保有玉を再計算 | 継続シグナル（0.5）に対して ATR で株数を計算し直し、差分が部分売却として板に出る（年 30 回） | 修正済み: 保有中は株数を変えない |
| `orders_today` が JST 日付 | `placed_at` は UTC。JST 0〜9 時の実行で当日件数が 0 に見え、上限が効かない | 修正済み: `Journal.today()`（UTC） |
| 「RSI(3)<20 かつ 終値>前日高値」 | 同時に成立しない（反発すると RSI(3) が跳ねる） | 前日 RSI ＋ 当日陽線に変更。最終的には反転確認自体を廃止 |

## 2. 押し目買い（`trend_pullback` 元版、コミット 165931f）

### 2.1 ルール

トレンド（終値>SMA200、SMA50>SMA200、SMA50 上向き）、60 日高値から ≤15%、
RSI(3)<20、ATR 1.5〜5%、売買代金 ≥$5M、SPY>SMA50、決算ブラックアウト。
スコア = 0.35 押し目深さ ＋ 0.30 SMA20 乖離/ATR ＋ 0.20 トレンド ＋ 0.15 流動性。

### 2.2 最初の結果と原因分解（2025-01〜2026-08、−6.5%）

| 手仕舞い理由 | 回数 | 勝率 | 平均 | 合計 |
|---|---|---|---|---|
| 逆指値 1.5×ATR（場中） | 44 | 5% | −3.0% | −$6,087 |
| 時間切れ | 25 | 28% | −0.7% | −$835 |
| 戦略の手仕舞い（RSI≥80／SMA20 回復／高値） | 52 | **90%** | +2.2% | +$5,032 |

→ 入口は機能。出口（損切りの非対称性）が原因。

### 2.3 出口の網羅比較（2019-01〜2026-08、等分フル投資、SPY +242%）

| 出口 | 総リターン | DD | n | 勝率 | 勝/負 |
|---|---|---|---|---|---|
| 元（1.5ATR 場中＋時間切れ） | +23% | 17% | 950 | 50% | +2.8/−2.6 |
| 時間切れなし | +24% | 15% | 915 | 52% | |
| 2.5ATR | +23% | 13% | 745 | 66% | |
| 4ATR | +32% | 7% | 631 | 75% | |
| **2.5ATR を終値判定に** | **+50%** | 9% | 688 | 71% | ← 最大の改善 |
| 終値 2.5ATR ＋ 反転確認なし | +54% | 22% | 635 | 67% | |
| 4ATR トレーリング・利確緩め・等分（L） | +112% | 11% | 617 | 82% | +2.4/−7.3 |
| **L ＋ 反転確認なし（L2）** | **CAGR 16.9%** | 11.7% | 650 | 76〜82% | |
| 利確なし ＋ 5ATR トレーリング（O） | CAGR 11.8% | 20% | 98 | 51% | +16.3/−7.3 |
| 利確なし ＋ 6ATR | CAGR 14.6% | 27% | | 50% | |
| SMA50 割れで手仕舞い | **−6%** | 30% | | 41% | エントリーが SMA50 付近なので即ダマシ |
| SMA20 割れで手仕舞い | +20% | 23% | 1050 | 47% | 同上 |

効果の大きい順: 場中→終値判定、損切り幅 1.5→4ATR、時間切れ廃止、
反転確認廃止、等分フル投資。効かなかった: 建値移動（発動前に降りる）、
SMA 割れ手仕舞い、部分利確。「早く利確（勝率 82%・DD 12%）」と
「伸ばす（勝率 50%・DD 20〜27%）」は CAGR が同程度で性格の選択。

L2 の年別（戦略/SPY）: 2019 +20/+31、2020 +38/+17、2021 +30/+31、
2022 −9/−19、2023 +27/+27、2024 +21/+26、2025 +6/+18、2026 +3/+13。
SPY に勝った年 3/8。

## 7. 再現方法

```bash
wbjp data sync --config-dir config/us --days 4400 --force      # 12 年分
wbjp backtest --config-dir config/us --from 2019-01-01
wbjp backtest --config-dir config/us-momentum --from 2015-09-01
```

出口別の集計・年別比較・投下率の測定は、`BacktestRunner` の
`broker.place` をラップして `OrderRequest.reason` を注文 ID ごとに記録し、
約定を FIFO で往復に組んで集計した（スクリプトは scratchpad で使い捨て。
必要なら `wbjp backtest --by-exit` として正式化する価値がある）。
